# Risc0 Proving

ProofGate uses the same Risc0 SDK release pinned by Logos Execution Zone:

- `risc0-zkvm = 3.0.5`
- `risc0-build = 3.0.5`
- `cargo-risczero = 3.0.5`
- `r0vm = 3.0.5`
- Risc0 guest Rust component `1.97.0`

The Cargo requirements use an exact `=3.0.5` constraint. A normal `3.0.5`
requirement permits Cargo to select `3.0.6`, which would change the build and
potentially the receipt interoperability assumptions.

## Development Mode Guard

The host prover rejects `RISC0_DEV_MODE=1`, `true`, or `on`. Real proof
runs should set the value explicitly:

```bash
RISC0_DEV_MODE=0 cargo test -p attestation-prover \
  real_succinct_proof_round_trip -- --ignored --nocapture
```

The ignored test generates a succinct receipt, verifies it against the image ID,
serializes it, decodes it, verifies it again, and compares the decoded journal
with the host-evaluated statement.
